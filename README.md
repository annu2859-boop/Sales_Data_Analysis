# Sales Data Analysis Using MySQL

## Project Overview
This project focuses on analyzing sales data using MySQL. The main objective is to extract meaningful business insights from sales data using SQL queries.

## Tools Used
- MySQL
- MySQL Workbench

## Database Name
`sales_analysis`

## Database Tables
1. customers
2. products
3. orders
4. order_items

## Key Analysis Performed
- Total Revenue Analysis
- Customer Spending Analysis
- Product-wise Revenue Analysis
- Category-wise Revenue Analysis
- Monthly Revenue Analysis
- Top Customers Analysis
- Top-selling Products
- Customer Segmentation
- Order Frequency Analysis

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- JOINS
- Subqueries
- Common Table Expressions (CTE)
- Window Functions
- Views
- Stored Procedures
- Triggers
- Indexes
- Aggregate Functions

## Revenue Calculation
Revenue is calculated using:

`SUM(quantity * unit_price)`

## Project Objective
To develop practical SQL skills and perform business analysis by extracting useful insights from sales data.
