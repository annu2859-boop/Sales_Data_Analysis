# Sales Data Analysis Using MySQL

## Project Overview
This project focuses on analyzing sales data using MySQL to extract meaningful business insights and answer important business questions.

## Tools Used
- MySQL
- MySQL Workbench

## Database Tables
- Customers
- Orders
- Order_Items
- Products

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Views
- Stored Procedures
- Triggers
- Indexes
- CASE Statements

## Business Analysis
- Total Revenue Analysis
- Customer Spending Analysis
- Product-wise Revenue
- Monthly Sales Analysis
- Customer Segmentation
- Top Customers Analysis
- Product Sales Analysis

## Project Objective
The objective of this project is to practice SQL skills and perform business analysis to understand sales performance, customer behaviour, and product performance.
